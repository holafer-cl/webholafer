En [[estadística]], un [[modelo]] de predicción que utiliza un [[conjunto]] de variables no correlacionadas obtenidas a partir de un [[ANÁLISIS DE COMPONENTES PRINCIPALES]] como predictor o VARIABLES INDEPENDIENTES. El beneficio de este enfoque es que el conjunto original de predictores en el modelo puede haber estado tan altamente interrelacionado como para dar como resultado [[COLINEALIDAD]]. El inconveniente es que si las variables no correlacionadas no son interpretables entonces el [[problema]] de la colinealidad no se resuelve ([Zedeck et al., 2013](https://www.apa.org/pubs/books/4311019)).
